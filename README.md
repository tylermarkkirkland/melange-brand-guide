# Melange Mercantile: Brand Guide

A scroll-driven brand guide for [Melange Mercantile](https://github.com/tylermarkkirkland/melange-mercantile), a fictional Dune-inspired luxury house. *Spice · Trade · Influence.*

It walks through the brand one chapter at a time, like a presentation: the brand itself, color, type, the logo, imagery, and the process behind it.

This is a personal project and the companion to the [Melange Mercantile website](https://github.com/tylermarkkirkland/melange-mercantile).

## Built with

React, Vite, and three.js for the 3D logo mark.

## Run it locally

```bash
npm install
npm run dev
```
